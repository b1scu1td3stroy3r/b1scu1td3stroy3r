8. Key Security Lessons & Remediation Matrix



  
    

      Vulnerability Category
      Observed Flaw
      Recommended Remediation
    

  
  
    

      Access Control / Information Leak
      /api/status exposed hardware serial number without authentication.
      Implement mandatory session middleware on all API routes; bind diagnostic interfaces strictly to localhost or private management VLANs.
    

    

      Default Authentication
      Hardware serial number accepted as factory-default administrative password.
      Require credential rotation to a unique, strong password during initial device onboarding.
    

    

      Cleartext Credential Exposure
      Management UI rendered local Windows operator credentials in plaintext.
      Remove cleartext credentials from UI templates and employ credential isolation.
    

    

      Kiosk Isolation Failure
      Support links spawned an unrestricted browser, enabling File Explorer and PowerShell invocation.
      Deploy Windows Assigned Access (Single-App Kiosk Mode) and restrict shell execution via AppLocker / WDAC.
    

    

      Cleartext Automation Scripts
      Database root credentials stored in plaintext within world-readable batch files.
      Utilize Group Managed Service Accounts (gMSA) or Windows Credential Manager, and grant minimal required DML privileges.
