Skills Used & Key Concepts

Service & Port Enumeration Full TCP port mapping using Nmap to isolate open network entry points.

2. Web Application & CMS Enumeration

Accessing the web portal via orion.htb revealed an Orion Telecom service platform running on CraftCMS version 5.6.16, executed by the user www-data[cite: 6, 7].

3. Configuration Analysis & Credential Recovery

Inspecting application configuration files unmasked the .env file containing database credentials[cite: 6]. Querying the MySQL instance revealed internal user passwords such as darkangel[cite: 6].

Local socket analysis performed via `ss` exposed internal-only listening services bound locally:

adam@orion:~$ ss -tlnup
Netid  State   Recv-Q  Send-Q  Local Address:Port    Peer Address:Port Process  
udp    UNCONN  0       0       127.0.0.53%lo:53         0.0.0.0:*             
tcp    LISTEN  0       10          127.0.0.1:23         0.0.0.0:*             
tcp    LISTEN  0       4096     127.0.0.53%lo:53         0.0.0.0:*             
tcp    LISTEN  0       80          127.0.0.1:3306       0.0.0.0:*             
tcp    LISTEN  0       128          0.0.0.0:22          0.0.0.0:*             
tcp    LISTEN  0       511           0.0.0.0:80         0.0.0.0:*             
tcp    LISTEN  0       128              [::]:22             [::]:*

This confirmed a local Telnet service (version 2.7) running on port 23[cite: 6].

4. Initial Access & User Flag

Using harvested credentials, SSH access was established as the user adam:

ssh adam@10.129.244.146

Navigating to the home directory allowed reading the user flag:

adam@orion:~$ cat user.txt
[REDACTED_USER_FLAG]

5. Privilege Escalation & Root Flag

System enumeration enabled administrative escalation to the root account. Accessing the root directory yielded the final flag:

root@orion:~# cat /root/root.txt
[REDACTED_ROOT_FLAG]
