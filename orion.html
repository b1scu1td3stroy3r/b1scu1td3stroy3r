Hack The Box: Orion — Write-Up

Target OS Linux
Target IP 10.129.244.146
Application Stack CraftCMS 5.6.16, Nginx, MySQL, Telnet (Local)
Exploitation Path Web Recon → CMS Enumeration → Database Config Leak → Local Service Pivoting → Root Shell

Skills Used & Key Concepts

Port & Service Scanning Enumerating listening ports with Nmap, identifying web services and local-only sockets.
CMS Version Auditing Fingerprinting CraftCMS versions and identifying application context and runner accounts (`www-data`).
Configuration Leakage Extracting database connection secrets and environment variables from hidden configuration files (`.env`).
Local Service Enumeration Discovering local-only listening services like Telnet (version 2.7) and MySQL database instances.
System Privileges Accessing user home directories and escalating to root privileges to retrieve system flags.

2. Web Enumeration & CraftCMS Analysis

Adding orion.htb to the local hosts file allowed access to the Orion Telecom web application running Nginx and CraftCMS.

  • Open TCP Ports: 2 (Port 22 SSH and Port 80 HTTP)[cite: 5]
  • CraftCMS Version: 5.6.16[cite: 5]
  • Running User: www-data[cite: 6]
  • Database Configuration File: .env[cite: 6]

3. Credential Discovery & Database Access

Reviewing the application environment variables and configuration files (`.env`) uncovered database credentials. Querying the internal MySQL database (listening locally on port 3306) yielded authentication details such as user passwords (e.g., darkangel)[cite: 6].

Local socket enumeration also revealed internal services bound exclusively to localhost:

adam@orion:~$ ss -tlnup

Notably, a local Telnet service (version 2.7) was found running on port 23[cite: 6, 7].

4. Initial Access & User Flag

Using discovered credentials, SSH access was established as user adam:

ssh adam@10.129.244.146

Navigating to the user's home directory revealed the user flag:

adam@orion:~$ cat user.txt
[REDACTED_USER_FLAG]

5. Privilege Escalation & Root Flag

Enumerating system privileges and local administrative scripts allowed escalation to root. Accessing the root user's home directory provided the final flag:

root@orion:~# cat /root/root.txt
[REDACTED_ROOT_FLAG]
